# Cardoryx V1.1 — Consigli Cardoryx

Basata sulla V1.0 Stable.

## Novità
Nei Dettagli carta è stata aggiunta la sezione **💡 Consigli Cardoryx**.

Analizza automaticamente:
- rarità
- variante
- valore Cardmarket
- quantità
- condizione
- stato di protezione

Livelli: **Standard**, **Da proteggere**, **Prioritaria**.

Può consigliare protezione, sleeve/top loader, controllo della condizione, aggiornamento del prezzo e gestione delle copie multiple. I suggerimenti non modificano automaticamente lo stato della carta.
